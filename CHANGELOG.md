# Changelog

All notable user-visible changes are recorded here.

## 2.0 RC5 — Public beta candidate

- Added the Windows removable-media and ESX bank manager.
- Added card capacity, free-space, file-count, and ESX bank display.
- Added direct bank opening and verified safe bank saving.
- Added warnings for the documented ESX-SD card and file limits.
- Confirmed the complete Windows card workflow: detect, save, reopen, and resave.
- Marked physical Korg ESX-SD loading as a community beta test.
- Preserved all RC4 sample, pattern, preview, song, and global/MIDI features.

## 2.0 RC4

- Added eight editable pattern bars with corrected ESX step alignment.
- Added selected-sample preview inside Pattern Studio.
- Added the 14-part live preview mixer.
- Added installable and portable Windows x64 packages.
